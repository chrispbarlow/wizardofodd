# Wizard of Odd Racing

**Wizard of Odd Racing** is a slightly fictional race team building a largely non-sensical VW-based Wizard Roadster powered by an Alfa Romeo 1.7 16v boxer engine running Megasquirt EFI.

The car is being built under its original name, **Scarlet**, having been christened by a previous owner long before it became anyone's problem. Scarlet has since evolved into an engineering testbed, marketing vehicle and occasional conversation piece.

This repository contains the digital assets associated with the project, including calibration data, CAD models, documentation and artwork.

## Repository Contents

### `/tunerstudio`

TunerStudio projects, tune files, logs and related ECU configuration.

As a general rule, tune files should be committed both before and after significant changes.

Future Chris is a stakeholder in this repository.

### `/cad`

CAD models, fabrication drawings, brackets, adapters and solutions to problems that would not exist if this were a straightforward restoration.

### `/artwork`

Logos, decals, livery concepts and other visual assets.

### `/docs`

Engineering notes, wiring information, build records and supporting documentation.

## Project Objectives

The immediate objective is straightforward:

1. Make it run.
2. Make it drive.
3. Make it stop.
4. Get it to Race the Waves.

Everything beyond that is likely scope creep.

---

## Build Philosophy

Scarlet is not intended to be a restoration project or show car.

The focus is on engineering progress, reliability, learning and enjoying the process. Cosmetic work is deliberately secondary to mechanical completion.

Current visual specification:

- Full red-oxide finish
- Acid green detail accents
- Minimal concern for conventional good taste

---

## Engineering Principles

Where practical:

- Prefer simple solutions
- Prefer reversible modifications
- Document important decisions
- Version control calibration data
- Avoid repeating mistakes

Where impractical:

- Refer to Git history.
